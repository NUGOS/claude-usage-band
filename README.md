# usage-band

Мод для Claude Code. Над полем вводу показує смугу з використанням контексту, залишком лімітів і вартістю сесії:

```
Контекст: ████░░░░░░ 42% (84k/200k)  │ 5 год: залишилось 63% (скид. 2г 15хв)  │ 7 днів: залишилось 88% (скид. 3д 4г)  │ $1.27
```

- Колір: зелений до 70%, жовтий від 70%, червоний від 90%.
- Ліміти видно лише на підписці Pro/Max і тільки після першої відповіді в сесії.
- `/usage-band` ховає смугу або знову її показує.

## Встановлення

Репозиторій приватний, тому Claude Code потрібен доступ до GitHub (`gh auth login` або `GITHUB_TOKEN`).

```
/plugin marketplace add NUGOS/claude-usage-band
/plugin install usage-band@claude-usage-band
```

Після встановлення виконайте `/reload-plugins` або перезапустіть Claude Code.
